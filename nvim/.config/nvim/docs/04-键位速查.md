# 04 · 键位速查

Leader 键 = **空格**。按下空格停顿一下，which-key 会弹出提示。

**忘了键位就按 `<leader>sk`**（模糊搜索所有键位）。
**想知道某个键是谁定义的**：`:verbose map gd`

「来源」一列告诉你这个键是哪来的：`原生` = Neovim 自带，其余为插件名或配置文件名。

## 折叠

| 键 | 作用 | 来源 |
|---|---|---|
| `za` | 切换当前折叠 | **原生** |
| `zR` / `zM` | 全部展开 / 全部折叠 | **原生** |
| `zj` / `zk` | 跳到下/上一个折叠 | **原生** |

配置里 `foldlevel = 99`，所以打开文件时默认全部展开，要折叠时手动按 `za`。
