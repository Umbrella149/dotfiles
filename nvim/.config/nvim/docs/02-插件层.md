# 02 · 插件层

## 插件管理器：vim.pack（Neovim 0.12 自带）

不需要 lazy.nvim。核心 API 只有 4 个：

```vim
:lua vim.pack.add({...})     " 声明要哪些插件（写在配置里，不手敲）
:lua vim.pack.update()       " 更新
:lua vim.pack.del({'名字'})  " 从磁盘删除
:lua vim.pack.get()          " 列出装了什么
```

插件文件实际存在：`~/.local/share/nvim/site/pack/core/opt/`
版本锁定文件：`nvim-pack-lock.json`（在配置目录，**建议纳入 git**）

---

## 加一个插件（4 步）

以加 `flash.nvim`（快速跳转）为例。

**1. 加到清单** —— 打开 `lua/plugins/deferred.lua`，在 `vim.pack.add` 里加一行：

```lua
vim.pack.add({
  ...
  gh('folke/flash.nvim'),     -- ← 新增
}, { confirm = false })
```

**2. 写配置文件** —— 新建 `lua/plugins/flash.lua`：

```lua
-- ============================================================================
-- flash.nvim —— 输入两个字符跳到屏幕任意位置
-- ============================================================================
require('flash').setup({})

vim.keymap.set({'n','x','o'}, 's', function() require('flash').jump() end,
  { desc = '快速跳转' })
```

**3. 注册** —— 在 `deferred.lua` 底部加：

```lua
require('plugins.flash')
```

**4. 重启 nvim** —— 会自动下载安装。

> 注意第 2 步里 `require('flash')` 的名字：它不一定等于仓库名。
> 看插件 README 的示例代码，或者看它 `lua/` 目录下的文件夹叫什么。

---

## 删一个插件（3 步）

```
1. 从 deferred.lua 的清单和 require 列表里删掉那两行
2. 删掉 lua/plugins/它.lua
3. 重启后执行 :lua vim.pack.del({'插件名'})
```

第 3 步不做的话，插件文件还在磁盘上占空间（但不会被加载，不影响使用）。

---

## 立即加载 vs 延迟加载

| 文件 | 什么时候加载 | 放什么 |
|---|---|---|
| `lua/plugins/init.lua` | 启动时 | **只有主题** —— 晚了会看到画面闪一下变色 |
| `lua/plugins/deferred.lua` | 界面画完后 | **其他所有插件** |

新插件默认放 `deferred.lua`。只有当你发现「这插件加载晚了会有视觉上的闪烁」时才移到 `init.lua`。

延迟加载的实现就在 `init.lua` 底部那 6 行（`UIEnter` + `vim.schedule`），
详见 [00-总览.md](00-总览.md#启动速度) 的说明。

# 各插件用法

## catppuccin —— 主题

`lua/plugins/catppuccin.lua`

```lua
flavour = 'mocha',   -- latte(浅色) / frappe / macchiato / mocha(最深)
transparent_background = false,   -- 改 true 让终端背景透出来
```

`integrations` 那一段是给各插件做配色适配，加了新插件后可以来这里看看有没有对应项。

**换成别的主题**：在 `deferred.lua` 或 `init.lua` 加新主题插件，
然后 `vim.cmd.colorscheme('新主题名')`。状态栏会自动跟着变色，不用改 `statusline.lua`。

## nvim-treesitter —— 下载语言 parser

`lua/plugins/treesitter.lua`

**它唯一的作用是下载 parser**，高亮逻辑在 `lua/core/treesitter.lua`（原生功能）。

加语言：在文件里的 `ENSURE` 列表加一行，重启自动装。
或者临时：`:TSInstall rust`

已配置：c、cpp、cmake、lua、vim、vimdoc、query、markdown、markdown_inline、
bash、json、yaml、toml、diff、gitcommit

```vim
:TSInstall <Tab>    " 看支持哪些语言
:TSUpdate           " 更新已装的 parser
```

## fzf-lua —— 模糊查找

`lua/plugins/fzf.lua`

**为什么选它**（而不是 telescope）：搜索交给你系统里已装的 `fzf` 和 `ripgrep`
这两个 C/Rust 程序，大仓库里明显更快，插件自身代码也少。

### 通用操作（打开任意搜索窗口后）

| 键 | 作用 |
|---|---|
| 直接打字 | 模糊过滤（字母不用连续，`mnc` 能匹配 `main.c`） |
| `<C-j>` / `<C-k>` | 上下移动 |
| `<CR>` | 打开 |
| `<C-x>` / `<C-v>` | 水平 / 竖直分屏打开 |
| `<Tab>` | 多选 |
| `<C-q>` | 把所有结果送进 quickfix 列表 |
| `<Esc>` | 关闭 |

### 主要键位

```
<leader><leader>   在打开的 buffer 之间切换   ← 最常用
<leader>ff         查找文件
<leader>fr         最近打开的文件
<leader>sg         全局搜索内容              ← 第二常用
<leader>/          在当前文件里搜索
<leader>sw         搜索光标下的词
<leader>sk         搜索键位（忘了快捷键就按这个）
<leader>sr         恢复上次的搜索
gd / gr / gI       跳定义 / 找引用 / 跳实现
```

完整列表见 [04-键位速查.md](04-键位速查.md)。

```vim
:FzfLua <Tab>       " 看它还有哪些搜索器（几十个）
```

## gitsigns —— git 行内标记

`lua/plugins/gitsigns.lua`

左边标记栏显示每行是新增 `┃`、修改 `┃` 还是删除。状态栏的分支名也是它提供的。

**术语**：hunk = 一块连续的改动。git 按 hunk 为单位暂存。

```
]h / [h            跳到下一处 / 上一处改动
<leader>gp         预览这处改动（不用切到终端 git diff）
<leader>gs         暂存这处改动
<leader>gr         撤销这处改动
<leader>gb         看这行是谁什么时候改的
dih                删掉整块改动（ih 是文本对象）
```

想让每行行尾都显示「谁改的」：把 `current_line_blame` 改成 `true`。

## mini.files —— 文件浏览器

`lua/plugins/mini-files.lua`

`<leader>e` 打开（当前文件位置），`<leader>E` 打开（项目根目录）。

**它的核心思路：把目录当成可编辑的文本列表。**

| 想做什么 | 怎么做 |
|---|---|
| 改文件名 | 直接像编辑文字一样改那一行 |
| 新建文件 | 新起一行写个名字 |
| 新建文件夹 | 新起一行写 `名字/`（末尾带斜杠） |
| 删除 | 删掉那一行（`dd`） |
| 移动 | `dd` 剪切那一行 → 进另一个目录 → `p` 粘贴 |
| 复制 | `yy` 复制那一行 → 进另一个目录 → `p` 粘贴 |
| **确认改动** | 按 `=`，会先弹确认列表给你看 |

导航：`h` 上级、`l` 进入/打开、`L` 打开并关闭浏览器、`q` 退出、`g?` 看全部按键。

**它是多列的**：越往右是越深的层级，所以做多层级操作时不会丢失上下文
（这是它和 oil.nvim 最大的区别 —— oil 每次只显示一个目录，占满整个 buffer）。

`permanent_delete = false` 表示删除是移到垃圾桶目录，误删了能找回来。

## mini.surround —— 引号括号操作

`lua/plugins/mini-surround.lua`

三个动作，都以 `s` 开头（s = surround）：

| 键 | 含义 |
|---|---|
| `sa` | **a**dd，加上包围符号 |
| `sd` | **d**elete，删掉 |
| `sr` | **r**eplace，替换 |

例子（光标在 `hello` 上）：

```
hello       按 saiw"    →   "hello"      给一个词加双引号
"hello"     按 sd"      →   hello        删掉双引号
"hello"     按 sr"'     →   'hello'      双引号换单引号
hello       按 saiw)    →   (hello)      加括号
```

`saiw"` 拆开看：`sa`(加) + `iw`(inner word，一个词) + `"`(用双引号)。
中间那部分是标准的 Vim 范围表示法，`sa2w)` 就是给两个词加括号。

visual 模式下选中内容后直接按 `sa"` 即可。

**注意**：它占用了 normal 模式的 `s` 键（原本等价于 `cl`，基本没人用）。

## which-key —— 按键提示

`lua/plugins/which-key.lua`

按下 `<Space>` 停顿 300ms，右侧弹出所有以 `<Space>` 开头的键位。

**弹窗里的说明文字来自各键位的 `desc`**，所以以后加键位时一定要写 `desc`。

```lua
preset = 'helix',   -- 外观：'classic'(底部横排) / 'modern' / 'helix'(右侧竖排)
delay = 300,        -- 弹出延迟（毫秒）。想更快就调小
```

底部的 `wk.add({...})` 是给前缀起组名，弹窗里显示「+文件」而不是一串键。
加了新的 `<leader>x` 系列键位后，记得来这里加一行 `{ '<leader>x', group = '名字' }`。

## conform —— 代码格式化

`lua/plugins/conform.lua`

### 这玩意儿到底是干什么的

「格式化」= 自动把代码排版整齐：缩进对齐、大括号该换行的换行、空格该加的加上。

每种语言有各自的格式化工具，它们是**独立的命令行程序**，用法各不相同：

- C/C++ → `clang-format`
- Lua → `stylua`
- Python → `ruff` 或 `black`
- 前端 → `prettier`

**conform 只做一件事：给这些工具提供统一入口。** 配好之后不管在什么文件里，
你都只按 `<leader>cf`，它自己去找对应的工具、处理光标位置、处理「只格式化选中部分」。

没有它的话你得记住每种文件跑哪个命令，还得自己处理这些细节。

### 格式化规则从哪来

**conform 不决定代码长什么样**，规则来自项目里的配置文件：

- C/C++ → 项目根目录的 `.clang-format`
- Lua → 项目根目录的 `.stylua.toml`

没有配置文件时用工具的默认风格。要改代码风格，是改那些文件，不是改 conform。

生成一个 `.clang-format`：

```bash
clang-format -style=llvm -dump-config > .clang-format     # 也可以用 google/mozilla/webkit
```

### 键位

```
<leader>cf     格式化（visual 模式下只格式化选中部分）
<leader>uf     开关「保存时自动格式化」
```

保存时自动格式化**默认关闭** —— 在别人的项目里容易搞出一堆无关 diff。
想默认开启就把文件里的 `vim.g.autoformat = false` 改成 `true`。

### 加一个语言的格式化

```lua
formatters_by_ft = {
  c = { 'clang-format' },
  cpp = { 'clang-format' },
  lua = { 'stylua' },
  python = { 'ruff_format' },   -- ← 新增
}
```

然后用 pacman 把工具装上：`sudo pacman -S ruff`

排查「为什么没格式化」：`:ConformInfo`（会告诉你找到了哪些工具、哪个不可用）。

**当前状态**：`clang-format` 已装（随 clang 一起）；`stylua` 未装，
要改 Neovim 配置本身的格式的话 `sudo pacman -S stylua`。
